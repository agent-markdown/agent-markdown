# Future directions

These topics are open for discussion, not additional v0.1 requirements. The current [spec](SPEC.md) already includes activities, timers, cards, basic forms, citations and media.

- Compact metadata for Markdown activity rows.
- Wikilinks, block references and transclusion with readable link fallback.
- Keyed component updates and revision ordering outside the Markdown body.
- Completed questions within a continuing stream; pending-input visibility.
- Approval expiry, retries and coordinated actions through host adapters.
- Citation ranges and structured provenance.
- Multi-question forms, richer validation and menus.
- HTML conversion, source-preserving round trips and optional preview bridges.

Use the [proposal template](CONTRIBUTING.md) with a concrete need, existing precedent, alternatives and fixtures. No new syntax is selected here.
