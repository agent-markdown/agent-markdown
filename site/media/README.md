# Local media fixtures

Synthetic fixtures created for the AFM examples; no external media dependency.

- `checks.svg`: authored chart, 8 checks before and 12 after.
- `tone.wav`: 220 Hz sine, 0.5 seconds, gain 0.05.
- `review.mp4`: white 360×160 canvas with a gray bar, two seconds, H.264 at 15 fps.

These demonstrate image/media mechanics, not a proposed chart grammar or an actual tool result.
