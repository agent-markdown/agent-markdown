# Inspirations

AFM builds on existing syntax and implementation patterns. These references do not imply endorsement or AFM support.

| Source | Influence |
| --- | --- |
| [CommonMark](https://spec.commonmark.org/0.31.2/) and [GFM](https://github.github.com/gfm/) | Baseline grammar, tables/tasks, and example-led rules |
| [HTML](https://html.spec.whatwg.org/multipage/) | Disclosures, native forms, media, timestamps and extensible data attributes |
| [Telegram](https://core.telegram.org/bots/api#formatting-options) | Compact formatting, underline/spoilers, paired Markdown and HTML forms |
| [Obsidian](https://help.obsidian.md/syntax) | Highlight and math conventions |
| [GitHub footnotes](https://docs.github.com/en/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github/basic-writing-and-formatting-syntax#footnotes) | Named references and readable source notes |
| [Nodes](https://github.com/nodes-app/swift-markdown-engine) and [Streamdown](https://github.com/vercel/streamdown) | Incremental display, renderer services and streaming equivalence |
| [Inline](https://github.com/inline-chat/inline), [Codex](https://github.com/openai/codex), [OpenCode](https://github.com/anomalyco/opencode) and [ClickClack](https://github.com/openclaw/clickclack) | Nested activity, evolving labels, tool results and stateful presentation |
| [ACP](https://agentclientprotocol.com/protocol/v1/tool-calls) and [MCP Apps](https://modelcontextprotocol.io/extensions/apps/overview) | Explicit lifecycle data and the separation of document content from host capabilities |
| [SwiftUI Menu](https://developer.apple.com/documentation/swiftui/menu) | Primary and supporting text interpreted through sibling order |
| [GitHub relative-time](https://github.com/github/relative-time-element) | Locally updated time display |

AFM defines its own selected grammar. Product UI, transport events and document syntax remain distinct; similar presentation does not establish a shared wire format.
